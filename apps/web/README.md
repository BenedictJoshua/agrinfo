# Primary Key web app

This is the React, TypeScript, and Vite frontend for the Primary Key Indian Agriculture Intelligence Platform.

## Run locally

From `apps/web`:

```powershell
npm install
npm run dev
```

The current foundation is a public, responsive landing page and location-explorer shell. It intentionally does not display live agricultural data until the API, source attribution, and availability states are implemented.

## Validate

```powershell
npm run build
npm run lint
```

The architecture and staged delivery plan are documented in the repository-level [`docs`](../../docs) folder.
